# RECIPE SYSTEM
__RECIPE SYSTEM__ is a console-based recipe management system, that allows users to create dishes, add them to recipes, scale portion sizes, and automatically generate a shopping list. \
In this particular project, only classes are implemented, as well as tests to verify their functioning. \
The creation of a fully functioning system was not required in this assignment.

# Downloading and running the script

### 1. Download script
```bash
git clone https://github.com/mthw07/recipe_system.git
cd recipe-system
```
### 2. Download requirements
Basically, the only thing you'll need to install is pytest.
```bash
pip install -r requirements.txt
```
### 3. Run the script
In fact, it is impossible to run the script, as my only task was to write specific classes and tests, respectively. \
So, you can move to the next step! (●'◡'●)

### 4. Run the tests
First, check that you are located in _.../recipe_system_ \
Then, type in this command to run the tests:
```bash
python -m pytest tests/test_recipes.py -v
```
